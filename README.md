
Game made with godot by kenny

Game features word grabbing from a [word api](https://random-word-api.herokuapp.com/), a simple timed word typing system, camera animations, death and merking animations and sfx, and uh your mom too

You can run it by connecting to wifi (only if you want random words, or you get a basic set), go to the [itch page](https://itchiback.itch.io/quick-draw), and press Run game!!
